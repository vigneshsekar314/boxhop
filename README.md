# README
Boxhop is a tool to explain, think and brainstorm concepts using diagrams with vim motions. Quickly draw and explain diagrams on the fly without cognitive load of drawing them.

## Quick actions

Use vim keybinds to type on a text editor. Use normal mode to exit typing. Normal vim motions help navigate through diagrams.
Create a new component using keybindings, then start typing after creation to fill in the details.

(Normal mode) <leader>w : wrap content in a box
(Normal mode) <leader>i : go into edit mode inside a component
